# Zeynep Çeltek Güzellik

Next.js 16 kurumsal site — güzellik salonu hizmet kataloğu, randevu sepeti, admin ve canlı editör.

## Stack

- Next.js 16 App Router + React 19 + TypeScript
- Tailwind 4 · Prisma 7 + MariaDB · Redux (sepet)
- Yayın: Hostinger Node.js (`docs/HOSTINGER.md`)

## Kurulum

```bash
npm install
cp .env.example .env
# MYSQL_* ve NEXT_PUBLIC_SITE_URL sonra eklenecek
npm run db:setup
npm run dev
```
